# Changelog

## 0.1.0-SNAPSHOT

- Extracted the plugin into a standalone project.
- Changed coordinates to `io.github.youngledo:jpackage-maven-plugin`.
- Changed Java package namespace to `io.github.youngledo.maven.jpackage`.
- Added goals for `jlink`, `jpackage`, and `leyden`.
- Added structured mappings for current JDK 26 `jpackage` option groups.
- Added command-generation tests for macOS, Linux, and Windows option groups.
- Added sample project skeletons for classpath Swing, classpath JavaFX, and JPMS Swing.
